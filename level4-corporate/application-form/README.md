# CareerConnect - Job Application Form

A responsive job application form built using HTML, CSS, and JavaScript.

## Features

- Personal details validation
- Education details validation
- Technical skills checkbox validation
- Multiple error messages
- Error summary at the top
- Success message after submission
- Automatic draft saving using localStorage
- Restore previously saved drafts
- Clear draft functionality
- Responsive design using CSS Grid
- Three responsive breakpoints

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Local Storage

## Project Structure

application-form/

├── index.html
├── style.css
├── script.js
└── screenshots/
    

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Fill in the application form.
5. Test validation and localStorage functionality.
