# TaskFlow – Task Manager

A responsive task management dashboard built using HTML, CSS, and JavaScript. It helps users organize daily tasks, track progress, and manage their work efficiently.

## Features

- Add new tasks with title and description
- Organize tasks by category
- Set task priorities: Low, Medium, and High
- Add due dates
- Edit and delete tasks
- Mark tasks as completed or pending
- Search tasks by title or description
- Filter tasks by status and category
- Dashboard statistics for total, pending, and completed tasks
- Save tasks using localStorage
- Responsive design for desktop, tablet, and mobile screens

## Technologies Used

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Browser localStorage

1. Clone or download this repository.
2. Open the `task-manager` folder.
3. Open `index.html` in your browser.
4. Start adding and managing tasks.
