# Expense Tracker 💰

A responsive Expense Tracker application built using HTML, CSS, and JavaScript.

## Live Demo

[View Expense Tracker](https://YOUR-USERNAME.github.io/expense-tracker/)

## Features

- Add income and expenses.
- View total income, expenses, and balance.
- Filter transactions by type.
- Edit existing transactions.
- Delete transactions.
- Select transaction categories and dates.
- Save transaction data using LocalStorage.
- Automatically restore data after refreshing.
- Responsive design for mobile, tablet, and desktop.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- LocalStorage
- CSS Grid
- Flexbox

## How to Run

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open index.html using Live Server.
4. Add income and expense transactions.
5. Refresh the page to check LocalStorage persistence.
